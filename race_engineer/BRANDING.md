# KerbSignal branding

New application mark: a racing-kerb/corner shape combined with radio-signal bars, in orange, ivory and graphite. The generated PNG was converted into project PNG sizes 32/64/128/256/512 and a multi-resolution Windows ICO. The app uses the same mark in its header and startup animation.

Project paths: `engineer/assets/kerbsignal-128.png` (startup), `engineer/assets/kerbsignal-32.png` (header), and `windows_build/raceengineer.ico` (Windows launcher/installer).

Created with the built-in image-generation tool. Prompt: “A premium square Windows application icon for KerbSignal: an original geometric circuit-corner/racing-kerb motif integrated with three radio-signal bars, suggestive of a forward-slanting K; strong negative space, crisp silhouette, racing orange, warm ivory and graphite; subtle dimensional highlights, dark rounded-square background; no text or surrounding scene; readable at small sizes.”
