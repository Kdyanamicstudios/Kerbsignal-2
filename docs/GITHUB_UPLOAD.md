# GitHub source handoff

This standalone repository contains the Windows/Python 0.15 source from the Codex continuation, with tests, build tooling, the canonical checklist and Windows validation evidence. It is separate from the existing KerbSignal repository and its Rust/Assetto Corsa work.

Start with README.md, WORK_IN_PROGRESS.md and docs/BUILD.md. Installer binaries, downloaded model weights, runtime DLLs, user settings and personal lap databases stay outside Git. The Windows test EXE and source ZIP are distribution files; normal source is visible directly in the repository.

Do not treat incomplete checklist rows as finished features. Source tests, package verification and actual iRacing/driver acceptance are separate.
